🚀 About

Pywer is a lightweight and fast Minecraft Bedrock Edition server software written entirely in Python.

The main goal of Pywer is to provide a simple, portable and developer-friendly Bedrock server that can run even on mobile devices.

«🐍 Built with Python
⚡ Async & Fast
📱 Mobile Friendly
📦 Single File
🧩 Pip Installable»

Currently, Pywer is being developed for Minecraft Bedrock 1.21.50.

---

✨ Why Pywer?

- ⚡ Fast asynchronous architecture
- 🐍 Written in Python
- 📱 Can run on mobile devices
- 📦 Can be installed using "pip"
- 📄 Single-file server
- 🪶 Lightweight
- 🛠️ Easy to modify and develop
- 🌐 Designed for Minecraft Bedrock Edition

---

📦 Installation

There are currently two ways to install Pywer.

🔹 Method 1 — Install with Pip

pip install pywer

Then run:

pywer

«Package availability may change while Pywer is under development.»

---

🔹 Method 2 — Download a Release

Go to the Releases section of this repository and download the latest release.

After downloading, run:

python pywer.py

---

▶️ Usage

After installation, simply start the server:

pywer

Or, if you're using the source file:

python pywer.py

The server will start and listen for Minecraft Bedrock connections.

📱 Mobile Support

One of the main goals of Pywer is being able to run a Minecraft Bedrock server directly on mobile devices.

For example, Pywer can be used in Python environments available on Android, making it possible to host a lightweight Bedrock server without requiring a traditional PC server.

«Performance depends on the device, world size, player count and server configuration.»

---

⚡ Performance

Pywer uses an asynchronous Python architecture to handle network operations efficiently.

The project is designed with lightweight execution and low overhead in mind.

The goal is simple:

Fast server. Small footprint. Easy development.
